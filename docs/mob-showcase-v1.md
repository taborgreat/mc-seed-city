# mob showcase V1

User-authorized showcase and cross-edition NPC handoff, 2026-09-13.

The delivered Java save and Bedrock `.mcworld` contain six roaming companions,
29 stationary looping animation exhibits and a separate glass Rat/creeper enclosure.
The barrel at 36,65,2 contains all six Creative spawn eggs. Both editions have
Creative inventory entries. Bedrock first-time showcase visitors also receive eggs.

## Java integration

Minecraft 26.2, Fabric Loader 0.19.5, Fabric API 0.160.0+26.2, Java 25.
`SeedCityItems` registers six ordinary SpawnEggItems using the entity-type component
and adds them to the Spawn Eggs tab. `rectifier_spawn_egg` spawns the unchanged
`seedcity:warden` entity ID. Spawn eggs do not bind city tasks automatically.

Actual inheritance is Builder -> FlyingCityMob -> PathfinderMob;
Warden/Courier/Collector/Sentinel -> PathfinderMob; RedstoneRat -> Cat. Rectifier now
walks with gravity at movement attribute 0.25 and stroll multiplier 0.6, matching the
iron golem's stroll without any protector AI. Old flying saves migrate on load.
Builder is allay-like
in flight, not an Allay subclass. Sentinel retains signal control, player targeting at
15, and knockback resistance 0.5 as a golem-like trait. It does not adopt IronGolem AI.
Rat taming/sitting are intentionally omitted; Tabor decides whether to add them later.

See the individual NPC merge notes and `Tabor-Integration-Guide.pdf`.

`ShowcaseAnimation` recognizes explicit synchronized names `SC:<pose>`; NoAI exhibit
mobs animate in place without doing real construction/mining/attacks. `ShowcaseRoaming`
only navigates mobs with the `seedcity_showcase_roam` tag. These are presentation helpers,
not a replacement for CityState orders. Free-roam Sentinel starts at signal 7.

`python tools/build_showcase.py` writes the explicit world-building function.
`/function seedcity:showcase/build` replaces x=-3..82,y=63..81,z=-3..65: new disposable
worlds only. Existing delivered saves are already built. ShowcaseClientTest generates
and saves the world in the test run directory; packaging removes test-only datapack
selection and renames the save to `mob showcase V1`.

## Bedrock integration candidate

`bedrock/SeedCityBP` and `SeedCityRP` are a separate implementation, generated by
`python tools/build_bedrock.py` from approved Blockbench cuboids and UVs. Client
animations use Molang. The stable server script API dependency is 2.0.0. No vanilla
entity files are replaced. Actual CityState, blueprint verification and gathering
task logic are not ported by the add-on.

Builder uses allay-style hover components; Rat has family `cat` so the native creeper
avoidance goal recognizes it; Sentinel has explicit `seedcity:signal_0` through
`seedcity:signal_15` events and player targeting at 15, matching Java. Tabor must wire
signal sources to these events. `seedcity:pose_<name>` freezes translation and selects
an exhibit animation. Ordinary entity spawning uses pose 0 and normal component AI.

Collector uses real iron tools in its native mainhand equipment slot. A periodic
command preserves either an iron axe or pickaxe and replaces missing tools. Its lamp
places `minecraft:light_block_12` only in air and persists owned positions for cleanup.
Cloth/lantern animation uses procedural motion rather than the Java motion helpers.

Bedrock Rectifier's generated egg ID is `seedcity:warden_spawn_egg` (displayed Rectifier).
`/function eggs` supplies a full set. `/function showcase` is the destructive fresh-world
builder. Resource and behavior packs must both be enabled.

## Validation and limits

- Java assembly, unit tests, seven client tests and inspected world screenshots passed.
- All 34 Java server tests passed for this update, including player-target creeper avoidance. An earlier run failed the random flee-path
  Rat test and timed out in city growth; no tests were weakened or unrelated city code changed.
- Official Bedrock Dedicated Server 1.26.45.1 loaded the pack, generated the world,
  and found all 37 actors. Six spawn-egg ItemStack IDs resolved. Native mainhand tool
  selectors found six Collectors with pickaxes; the chop display then received an axe.

  from 3 to 16.01 blocks in one run and 14.34 in a second after eight seconds.
- **Bedrock client rendering, tool attachment alignment, animation transitions and
  console/mobile import have not been visually tested.** Review this candidate in the
  client before treating Bedrock visual parity as approved. Java art remains approved.

The worlds and install files are packaged as local user-facing deliverables; source,
the PDF and screenshots live in the fork for review. No full vanilla server binaries
are distributed in the handoff.
